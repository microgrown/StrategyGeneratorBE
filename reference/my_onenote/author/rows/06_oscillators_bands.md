# Slice 06_oscillators_bands: CATALOG rows

The RSI rules inline `RsiBelowThreshold`'s bit-exact `WFSafe_RSI` port (seed on the first calculated bar, `SF = 1/Length`, no re-seed on a length change). The ADX rules inline `AdxBelowThreshold`'s `WFSafe_ADX` port. In both, the EL twin stores the function in a variable and reads its history (`rsiVal[k]`, `adxVal[k]`), which is 0 before the first evaluated bar. The C++ mirrors that history in a zero-seeded newest-first buffer. A rule whose deepest lagged read would hit that zero fill waits for `CurrentBar > k` in both twins (the B-list EMA-lag convention). The Bollinger rules use `BollingerBandCross`'s band construction (fresh newest-first `Average`, population `StdDev`). Where a past bar's band is needed, it is open-coded at that offset in both twins, so it is computed from price and not read from a zero-filled band variable.
