# Slice 05_breakout_consolidation: CATALOG rows

The consolidation zone (ON-30-a) is `RangeWidthBelowAtrMultiple` with the new `lag` input at `rangeLookback = atrLookback = X`. `ConsolidationBreakoutFirstRetest` and `ConsolidationBreakoutBarHighClose` inline one breakout scan, copied verbatim: for k = 1 .. `maxWaitBars`, bar [k] is a breakout bar when the `zoneBars` bars ending at [k + 1] are a zone (that rule at lag k + 1, `el_le`) and bar [k] opened inside the zone and closed at least `breakoutAtr` × the same ATR beyond it (`ConsolidationBreakoutBar` at offset k). The first hit walking back is the most recent breakout. Bull and bear breakouts are tracked separately, one per side. `BreakoutDirectionShare` and `ConsecutiveUpsideBreakouts` share one breakout-event scan.

## Amended rows

Replacement rows for the two existing rules that gained a `lag` input (both twins edited). At `lag` 0 each computes exactly what it did before. The window starts at bar 0 and, in `RangeWidthBelowAtrMultiple`, a one-slot history returns this bar's ATR unchanged. The EL twin of `RangeWidthBelowAtrMultiple` now stores the ATR in a variable (`atrVal[lag]`) instead of calling `WFSafe_AvgTrueRange` inside the condition. Same value at lag 0.

| Rule | Type | Sides | Reaches back | Inputs | Fires when |
|---|---|---|---|---|---|
| `RangeWidthBelowAtrMultiple` | Entry | same | `max(lag + rangeLookback - 1, atrLookback + 1)` | `rangeLookback(20)`, `rangeAtrMultiple(4)`, `atrLookback(14)`, `lag(0)` | The height of the last N bars (highest high − lowest low) is no more than K × the N-bar ATR, the corpus's canonical trading-range classification. Loose (20 bars, 4.0) reads "in a trading range". Tight (15 bars, ~1.2) reads "tight trading range". Negate the placement for "trending". ATR is MW's rolling `WFSafe_AvgTrueRange`, not a fresh mean. `lag` reads the whole test `lag` bars ago: the window ending at bar [lag] and the ATR stored in a variable and read at [lag], zero-filled before the first evaluated bar (mirrored as a zero-seeded ring buffer, re-seeded if `lag` changes). `lag` 1 at `rangeLookback = atrLookback = X` is Brian's consolidation zone before a breakout bar (ON-30-a, #30; the note's strict `<` is this rule's `<=`, separated only by an exact tie).
