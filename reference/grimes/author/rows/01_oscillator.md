## Notes for the orchestrator

- **Input-name divergence, deliberate**: the two slow-line rules spell their ATR window `atrLength` (the merged parameter name) where the rest of the corpus spells it `atrLookback`. The C++ keeps the rolling accumulator's remembered length in a local called `atrSeedLen` so the two never collide. If the design-grid pass would rather match on `atrLookback`, renaming both twins is a one-line change.
- Every rule in the oscillator family carries its oscillator inputs (`fastLen`, `slowLen`, and `signalLen` where a slow line is read) so the family can be tuned as a unit.
- Ten of the eleven declare `std::vector<double>` / `std::size_t` locals for mirrored EL variable history, which `validateRule` reports as an "Unusual local type" warning — the same warning `BarRangeAboveStd`, `AtrRising`, `EmaSlope` and `AwesomeOscillatorSlope` already raise.
