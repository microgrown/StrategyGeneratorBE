The merged pseudocode spelled the up gap, which is the SHORT's cover target; the pair is mirrored, so the long side is written first — the same correction `ExtremeTestAfterTrendLineBreak` needed. THE LEVEL PERSISTS FROM THE BAR THAT MADE THE GAP, which is the whole difference from a window scan: a gap ten bars back and eighty bars back are the same magnet. STATEMENT ORDER IS PART OF THE SPECIFICATION and is what keeps a gap bar from firing on itself: the exit tests read the levels held COMING INTO the bar, a reached level is disarmed, and only then is this bar's own gap recorded — a bear-gap bar's high IS its level, so recording first would fire every down gap unconditionally. The level is MARKET structure, not position state, so it survives across trades and is never reset at entry (the call `TrailStopToMicroMeasuringGap` makes); it is disarmed once reached, because a filled gap is no longer a magnet, and the arming is a bool rather than a `level > 0` test because a back-adjusted contract can price below zero.
