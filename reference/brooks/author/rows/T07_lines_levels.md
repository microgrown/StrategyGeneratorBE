## Not written

None — all eight keys in the slice were authored. Two were checked hard and kept, with the relationship stated in the rule comment and the row above:

- `ChannelLineOvershoot` vs the on-disk `SignificantChannelLineOvershoot`: same line, same sides, but a TICK margin on bar 0 against an ATR magnitude over a window. They coincide only at `significantOvershootAtr = 0, lookback = 1`; a tick count is not expressible as an ATR fraction, which is the reason this key was held for the tick list.
- `TrendLineBreak` vs the on-disk `TrendLineBrokenRecently`: at `breakTicks = 0`, `withinBars = 1`, `minBreaks = 1` the two tests would agree bar for bar were it not for this rule's slope gate (the newer pivot must lie beyond the older one in the trend direction), which `TrendLineBrokenRecently` does not carry. The gate and the `breakTicks` margin are the added content; if Brian would rather have one rule, this is the one to drop.
