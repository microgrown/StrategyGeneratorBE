- **trade_management**: options=['fix it to a small set of round-number distances (e.g. whole points) and test each as an input', "derive it from recent realized volatility (e.g. an ATR multiple) as a proxy for 'typical' stop size", 'drop as discretionary, no bar-level test given']; recommended: drop -- the book gives no formula for 'the obvious stop size traders are using'; substituting an ATR proxy would be inventing a new rule, not mechanizing this one; gates: ['ScaleInJustBeyondObviousStopRunLevel']

### always-in / day-trend direction at entry
- **exits_targets**: options=['two consecutive strong trend bars flip the direction (V15-01/V15-03, the test Brooks states most often)', 'majority of the last N closes against an EMA', "sign of the session's move so far (close vs the session open)"]; recommended: two consecutive strong trend bars, matching whatever the context_regime bucket settles on; for the day-trend-at-entry gate specifically, the cheap session-open sign test is worth testing first; gates: ['CountertrendScalpTarget', 'ExitOnClimaxBarInMatureTrend']
